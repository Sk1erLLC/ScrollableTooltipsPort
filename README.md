# Scrollable Tooltips

Port Sk1er's Scrollable Tooltips mod to modern Minecraft versions. Original repo (1.8.9): https://github.com/Sk1erLLC/Scrollabletooltips

## About

Scrollable Tooltips allows you to scroll through item tooltips that don't fit on the screen, making it easier to read long descriptions, enchantments, and other tooltip information.

## Features

- **Vertical Scrolling**: Use the mouse wheel to scroll up and down through long tooltips
- **Horizontal Scrolling**: Hold Shift and use the mouse wheel to scroll left and right through wide tooltips
- **Client-side**: Works on any server, no server-side installation required
- **In-game Configuration**: Access configuration options directly from the game

## Installation

### Fabric
1. Install [Fabric Loader](https://fabricmc.net/use/)
2. Install [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)
3. Download the latest release from [Modrinth](https://modrinth.com/mod/sk1er-scrollable-tooltips/) or [Sk1er's website](https://sk1er.club/mods/text_overflow_scroll)
4. Place the mod file in your `.minecraft/mods` folder

### Forge/NeoForge
1. Install [Forge](https://files.minecraftforge.net/) or [NeoForge](https://neoforged.net/)
2. Install [Kotlin for Forge](https://modrinth.com/mod/kotlin-for-forge)
3. Download the latest release from [Modrinth](https://modrinth.com/mod/sk1er-scrollable-tooltips/) or [Sk1er's website](https://sk1er.club/mods/text_overflow_scroll)
4. Place the mod file in your `.minecraft/mods` folder

## Usage

Once installed, the mod works automatically:
- When viewing an item tooltip that extends beyond the screen, use your **mouse wheel** to scroll up and down
- Hold **Shift** and use your **mouse wheel** to scroll left and right

Access the configuration screen through Mod Menu (Fabric) or the Mods menu (Forge/NeoForge).
